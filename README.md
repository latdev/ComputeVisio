# ComputeVisio 👁️

Социальный проект из Латвии по созданию доступного помощника для незрячих.

## ⚖️ Этическая Лицензия
Этот проект защищен лицензией GPL v3. Я, автор проекта, устанавливаю дополнительное условие:
**Любое конечное устройство на базе этих наработок должно продаваться по себестоимости компонентов (target < 100$).** Если вы хотите заработать на этом бабло — проходите мимо. Мы работаем "за конфетку" ради свободы передвижения людей.

## 🚀 Концепт
* Носится на шее (руки свободны).
* Связь через Bluetooth-наушники.
* **Активный режим:** Сигналы о ямах и машинах.
* **Пассивный режим:** Голосовой разбор ценников, текста и окружения.
